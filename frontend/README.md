# Ramaz X1 Frontend

Simple dashboard for Ramaz X1.

## Features
- System status
- Agents list
- Run mission
- Mission results
- Missions history

## How to use

1. Start backend:
```bash
cd backend
py -m uvicorn main:app --reload
```

2. Open `frontend/index.html` in browser
   - Or serve it with any static server

API default address: `http://127.0.0.1:8000`
